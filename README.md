# 基于ESP8266的应援棒改造控制器


[代码仓库](https://github.com/liang0727/Flowing-Rainbow.git) 

[硬件开源](https://oshwhub.com/ldb0727/project_epzljoid)

## 简介

这是本人根据歌手邓紫棋的演唱会荧光棒改造的一个控制器。原有的荧光棒在出演唱会以后就不能发光，网上虽然有很多改造的教程，但是大多数都可以归为两类：
- 需要在外表穿孔加装按钮
- 需要额外下载软件进行控制

因此，本人就尝试自己做一个控制器，在不需要额外下载软件的情况下，通过手机控制荧光棒的开关。这样子无论使用哪一部手机都可以实现控制，也不用放一个平时用不到的软件在手机里吃灰。

## 原理
这个控制器的原理就是依赖ESP8266模块的WIFI功能，将ESP8266定为AP节点，然后在节点中设置DNS劫持，将手机访问的域名解析到ESP8266的IP地址上，这样子手机就可以通过域名访问到ESP8266模块。最后在ESP8266模块中设置一个HTTP服务器，通过手机访问这个HTTP服务器，就可以控制荧光棒的开关。

## 硬件
这个控制器使用的是ESP8266模块（主要是当时手边没有其他的无线通信的模块了）。ESP8266这个模块说实话，我感觉不是特别适合这个控制器
- 首先是ESP8266的能耗有点高。我个人对WiFi的AP模式的能耗没有概念，但是实测下来，连续开AP模式几个小时就可以把3节7号电池耗到没电，
- 其次是ESP8266的供电电压是3.3V，且驱动电流比较小，不足以直接驱动荧光棒上的RGB灯珠（这个是AI说的，我查到的资料确实也是这样）
- 最后是ESP8266的体积太大了

因此我在画这个PCB的时候，为了能让RGB灯珠更好的驱动，我又重新画了一块带灯珠和MOS管驱动的板。（Note:我画完这个板才发现，嘉立创的免费居然只能用在1.6mm的板上，而1.6mm又不能放进荧光棒的结构里，所以最后只能把板子做小了一圈，使用热熔胶固定住了）

对于带主控的这块PCB，我使用了一个不太规范的齿状结构，将主控和RGB灯珠的驱动板连接起来，这样子可以不用飞这么多的线。
